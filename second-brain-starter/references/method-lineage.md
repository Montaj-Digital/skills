# Montaj Digital method note

Use this when explaining the workshop method or writing public-facing notes.

## Public positioning

This is Montaj Digital's second brain starter method. It helps a person turn scattered context into a small folder of sources, reviewed knowledge, routing and review habits.

Use:

```text
This workflow is the Montaj Digital second brain starter: sources, reviewed knowledge, routing, decisions and an update habit.
```

Avoid naming external creators, frameworks or repositories in participant-facing materials. The workshop should feel like a Montaj-owned method, not a tour of other people's systems.

## Core method

The method has five parts:

1. **Sources:** original notes, transcripts, documents, links and pasted context.
2. **Reviewed knowledge:** concise pages that say what is known, assumed and unresolved.
3. **Routing:** an index that tells AI which files to use for which kind of task.
4. **Decisions:** a dated record of what changed, why and what source supports it.
5. **Review habit:** a simple cadence for updating the brain after meaningful work.

## Four practical layers

Teach these as Montaj's practical layers:

- **Context:** what AI should know before helping.
- **Connections:** where live information lives and whether access is manual, verified or proposed.
- **Capabilities:** repeatable workflows, prompts, skills or procedures.
- **Cadence:** when the person reviews, updates or automates the system.

Operational lessons:

- Start by interviewing the person. A lot of useful context is still in their head.
- A routing file matters because a large folder only helps if the AI can find the right files.
- Verify outputs against sources. Confidence isn't evidence.
- Build habits before automations. More autonomy raises cost, risk and maintenance.
- Prompt rules aren't a permission layer. Real tool access and scoped keys matter when integrations are added.

## Workshop version

The workshop version is intentionally smaller:

- One bounded project or area.
- One source.
- One reviewed brief.
- One fresh-conversation proof.
- One saved decision.
- One review habit.

The skill can grow later into team knowledge, connectors, recurring tasks and custom skills, but the first win is a reliable source-backed folder.

## Wording

Use:

```text
This is Montaj Digital's starter workflow for building an AI second brain you can actually reuse.
```

Avoid:

```text
This automatically syncs your whole business into AI.
```

```text
AI will remember everything after this.
```

```text
This is a complete operating system after one workshop.
```
