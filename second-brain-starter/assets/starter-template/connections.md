# Connections

Track where useful live information lives. Don't claim a tool is connected until access has been verified.

| Area | Tool or location | Status | What it should provide | Setup remaining |
| --- | --- | --- | --- | --- |
| Meetings |  | manual import |  |  |
| Tasks |  | manual import |  |  |
| Documents |  | manual import |  |  |
| Calendar |  | proposed connection |  |  |
| CRM or customers |  | proposed connection |  |  |

## Status meanings

- Manual import: copy or upload sources when needed.
- Verified access: the AI can read the source in the current environment.
- Proposed connection: useful later, but not set up.
- Recurring sync: automation exists and has been tested.

## Permission note

Prompt instructions aren't a permission layer. If a tool can send, edit or delete, restrict that access before using it in an automated workflow.
