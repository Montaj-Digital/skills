# Index

This is the routing map for the brain. Read this first.

## Start here

- `wiki/current-brief.md`: current reviewed context.
- `wiki/decisions.md`: approved decisions and superseded history.
- `wiki/open-questions.md`: gaps that should not be invented.
- `wiki/recurring-workflows.md`: repeatable tasks and how to run them.
- `connections.md`: where live information lives and what access exists.
- `raw/`: original source material.
- `wiki/sources/`: source summaries.

## Routing

| Need | Read |
| --- | --- |
| Understand the current situation | `wiki/current-brief.md` |
| Check a decision | `wiki/decisions.md` |
| Find missing information | `wiki/open-questions.md` |
| Run the first repeatable task | `wiki/recurring-workflows.md` |
| Add or verify a source | `raw/` and `wiki/sources/` |
| Plan an integration | `connections.md` |

## Rule

Choose the smallest useful set of files. Better answers come from relevant context, not dumping the whole folder into every task.
