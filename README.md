# Montaj Digital skills

Shareable skills from Montaj Digital workshops and resources.

## Second Brain Starter

`second-brain-starter/` helps someone build the first useful version of an AI second brain from scratch.

It guides the AI to:

- interview the user one question at a time
- preserve original source material
- create reviewed context pages
- build an index, log, decisions file and connection plan
- test whether a fresh AI conversation can use the saved context without inventing missing facts

The skill is designed for beginners. It starts with one bounded project, role or business area, then creates a portable folder the user owns.

## How to use

Copy `second-brain-starter/` into your local skills folder, then invoke it as:

```text
Use the Second Brain Starter skill to help me build my first AI second brain.
```

If your AI tool doesn't support local skills, open `second-brain-starter/SKILL.md` and paste its instructions into a new project or chat.
